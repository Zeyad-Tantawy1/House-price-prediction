# 🏠 House Price Prediction

##  Overview
This project focuses on predicting house prices using **Linear Regression** as a baseline model. It demonstrates how simple models, when combined with proper data preprocessing, can provide valuable insights.

##  Steps
- Data cleaning and preprocessing.
- Applied feature scaling and encoding.
- Implemented **Linear Regression** to model price predictions.

## 📊 Results
- The model captured key relationships between features (e.g., number of rooms, area size) and price.
- Provided a strong baseline for further exploration.

##  Next Steps
- Experiment with advanced regression models (Random Forest, Gradient Boosting).
- Apply cross-validation and hyperparameter tuning for optimization.
